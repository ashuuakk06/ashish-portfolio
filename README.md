# Ashish Pagariya — Portfolio

A personal portfolio built with React, TypeScript, Vite, Framer Motion, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Keep the terminal running while viewing the site.

## Production build

```bash
npm run build
npm run preview
```

The production files are generated in `dist/`.

## Project notes

- The hero uses a CSS-built developer profile illustration; no portrait is included.
- Project preview panels are CSS-built interface illustrations, not screenshots of live products.
- Update `src/App.tsx` to change profile text, project details, links, and skills.
- Replace `public/Ashish-Pagariya-Resume.pdf` to update the downloadable resume.
- The development server is bound to `127.0.0.1`. `server.fs.strict: false` is set for local development because this project folder is under OneDrive on Windows.
